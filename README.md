# Amazon-inspired eCommerce Webpage

This is a **responsive eCommerce webpage** inspired by Amazon, built using **HTML**, **CSS**, and **Font Awesome**. The webpage is designed to provide an engaging and seamless user experience across a variety of devices, from mobile phones to desktop computers.

## Features

- Responsive Design: Fully responsive layout using **CSS Flexbox** and **Grid**.
- Navigation Bar: Includes a dynamic navigation bar with logo, search bar, and account options.
- Product Display: Showcase product images and details in a grid layout.
- Photo Gallery: Horizontal scrollable gallery with featured products.
- Footer: Structured footer with multiple columns for links and information.

## Technologies Used

- HTML: For structuring the webpage.
- CSS: For styling and creating the responsive layout.
- Font Awesome: For icons like search and account options.
- Responsive Design: Implemented using CSS media queries to ensure the website works well on various screen sizes.
